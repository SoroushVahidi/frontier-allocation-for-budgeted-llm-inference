# Performance Evaluation Supplementary Material

This supplementary material supports the manuscript "Nominal Budgets and Realized Resources in
Closed-API Large-Language-Model Inference: A Performance Evaluation Protocol."

The package is intended for public artifact inspection. It contains manuscript-side claim maps, numerical
consistency checks, figure/table audits, and final compliance/page/redundancy audits. It does not
contain credentials, live API scripts, or instructions that require paid API calls.

## Contents

- `CLAIM_EVIDENCE_MAP.md`: maps manuscript claims to frozen evidence records.
- `CLAIM_SCOPE_AUDIT.md`: records claim-boundary checks.
- `NUMERICAL_CONSISTENCY_CHECK.md`: records numerical consistency checks.
- `FIGURE_TABLE_AUDIT.md`: figure and table audit from Pass 5.
- `LAYOUT_AND_PAGE_AUDIT.md`: layout audit from Pass 5.
- `REDUNDANCY_FINAL_AUDIT.md`: final redundancy consolidation audit.
- `JOURNAL_COMPLIANCE_FINAL_AUDIT.md`: official-source compliance audit.
- `PAGE_LENGTH_AUDIT.md`: final page-count and layout audit.
- `CHECKSUMS_SHA256.txt`: SHA-256 checksums for packaged files.

## Reproducibility Boundary

The manuscript reports deterministic replay over frozen records. Live regeneration of proprietary
closed-API outputs is outside this submission package and may incur API charges. The supplementary
material therefore supports claim tracing and replay documentation, not new experiment execution.

## Author Metadata Boundary

Affiliations, emails, ORCID fields, acknowledgments, funding details, and competing-interest
wording require final author confirmation before journal upload.
