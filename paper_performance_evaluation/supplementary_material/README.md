# Performance Evaluation Supplementary Material

This supplementary material supports the manuscript "Nominal Budgets and Realized Resources in
Closed-API Large-Language-Model Inference: A Performance Evaluation Protocol."

The package is intended for public artifact inspection. It contains manuscript-side claim maps, numerical
consistency checks, figure/table audits, and final compliance/page/redundancy audits. It does not
contain credentials, live API scripts, or instructions that require paid API calls.

## Contents

- `CLAIM_EVIDENCE_MAP.md`: maps manuscript claims to public aggregate records, source tables, and
  reproducibility checks.
- `CLAIM_EVIDENCE_PUBLIC_MAP.md`: public-facing copy of the claim-evidence map.
- `PUBLIC_ARTIFACT_CONSISTENCY_AUDIT.md`: records the targeted correction pass that aligned the
  manuscript, supplement, package, and public repository evidence boundary.
- `CLAIM_SCOPE_AUDIT.md`: records claim-boundary checks.
- `NUMERICAL_CONSISTENCY_CHECK.md`: records numerical consistency checks.
- `HISTORICAL_DIAGNOSTICS_SUPPLEMENT.md`: preserves historical diagnostics and pilots removed from
  the journal manuscript because they are outside the evaluated protocol; it also preserves the
  descriptive discovery-selection scatter diagnostic moved out of the appendix.
- `FIGURE_TABLE_AUDIT.md`: figure and table audit from Pass 5.
- `LAYOUT_AND_PAGE_AUDIT.md`: layout audit from Pass 5.
- `REDUNDANCY_FINAL_AUDIT.md`: final redundancy consolidation audit.
- `JOURNAL_COMPLIANCE_FINAL_AUDIT.md`: official-source compliance audit.
- `PAGE_LENGTH_AUDIT.md`: final page-count and layout audit.
- `FINAL_EDITORIAL_CORRECTIONS_AUDIT.md`: final targeted correction audit for the Performance Evaluation submission.
- `CHECKSUMS_SHA256.txt`: SHA-256 checksums for packaged files.

## Reproducibility Boundary

The manuscript reports deterministic verification over public aggregate records and source tables.
Live regeneration of proprietary closed-API outputs is outside this submission package and may incur
API charges. The supplementary material therefore supports claim tracing and replay-boundary
documentation, not new experiment execution.

## Author Metadata Boundary

The identified manuscript and submission assets include confirmed author metadata, acknowledgments,
funding, competing-interest, data/code availability, and AI-use statements. The anonymous manuscript
is retained only as a fallback for workflows that request an anonymous manuscript file.
