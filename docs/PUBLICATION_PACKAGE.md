# Publication Package

The public repository is a clean release repository. It intentionally excludes:

- private review and venue-submission workflow material;
- historical pull-request and issue history from the private research repository;
- local virtual environments and caches;
- ignored run logs and private generated workspaces;
- credentials, account identifiers, and API keys;
- third-party code snapshots not needed for the manuscript release.

The Performance Evaluation package remains under `paper_performance_evaluation/`.
