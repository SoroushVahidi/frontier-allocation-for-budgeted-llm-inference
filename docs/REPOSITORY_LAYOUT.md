# Repository Layout

| Path | Purpose |
| --- | --- |
| `experiments/` | Core implementation for controllers, selectors, answer normalization, and accounting. |
| `scripts/` | Offline replay, validation, and health-check entry points. |
| `configs/` | Experiment and adapter configuration files. |
| `tests/` | Offline regression tests included in the public release. |
| `outputs/final_4x4_matrix_conclusive_audit_20260717T223631Z/` | Compact canonical provider-by-dataset matrix audit. |
| `paper_performance_evaluation/` | Performance Evaluation manuscript source, figures, PDFs, and submission assets. |
| `prompts/` | Prompt templates used by the research code. |
| `datasets/` | Dataset notes; datasets themselves are public upstream resources. |
