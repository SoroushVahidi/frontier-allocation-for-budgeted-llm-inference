# Public Release Documentation

This directory contains public-facing documentation for the release repository.

- `REPOSITORY_LAYOUT.md`: top-level directory map.
- `REPRODUCIBILITY.md`: offline setup, checks, and manuscript compilation commands.
- `DATASETS.md`: public dataset availability statement.
- `ARTIFACT_MAP.md`: compact map from manuscript claims to released artifacts.
- `PUBLICATION_PACKAGE.md`: package inventory and release boundary.
